# かく あそび 仕様（kaku-asobi）（案）
出典：『認知発達治療の実践マニュアル』Stage I「6-2 描くことの基礎」（p.42〜43）。6-1（さす）は さす あそび、6-3（ハサミ・紙）は別アプリの予定。

## 要約（本の内容）
目と手の協応を、描く・なぞる・ぬる・点を結ぶ、の順に広げる。
(1) 自由に線を描く：左右の線、上下の線、円状の線。大人が軽く手を添える。「おえかきせんせい」などを使って楽しく。
(2) 線や形をなぞる：なぞり板（直線・曲線をくりぬいた板）、はめ板、コップ、空き缶の輪郭をなぞる。
(3) 円を描く：大人が描いてみせ、子どもが真似る。
(4) 色をぬる：○△□などの型の中をぬる。型の板があると、枠を意識しやすい。
(5) 点線をなぞる：短い直線（10cm くらい）から、曲線や角のある線へ。
(6) 点から点に線を引く：点から書き始め、点で止まる。はじめはシールを二重三重に貼り、その間を結ぶ。

## 実装した画面（初版）
- 場面（6つ。最初から全部選べる。選ぶ場所は支援者メニューの一番上、絵つきボタン）
  - 自由に描く：指で線を描く。場面を変えても、この絵は残る（開いている間だけ。保存しない）
  - なぞる：溝（なぞり板）を、緑の点から金の輪までなぞる。なぞった所に色がつき、溝の近くでふちが光る（点滅なし）。道は 直線／曲線／角のある線
  - 円を描く：見本の円がゆっくり描かれ（約3秒）、そのあと子どもが描く。ほぼ1周して始点に近づくと円と認める（手助けで厳しさが変わる）。直線などは円とみなさない（いやな音は出さない）
  - ぬる：○△□（順にも）の中をぬる。色は型の中だけにつく。ほぼぬると、のこりが自動でぬられる
  - 点線をなぞる：点線を順になぞると、点が色づき小さな音が鳴る。道は 直線／曲線／角のある線
  - 点を結ぶ：光る点から次の点へ線を引く。点は番号なし。点数 3／5／8。届くと、ぽんと鳴って星
- ガイドのある場面は、できるとベル3音と星、約3秒後に新しい紙になる（絵は消える。保存しない）
- 線の太さ：太い／細い（自由・なぞる・点線）
- 手助け：大きい＝ガイドに広く吸いつく（点を結ぶは点線の手がかりが出る）／ふつう／小さい＝ガイドに正確に（点を結ぶは、点で線が止まり、指を離してから次を引く）
- 音：線は紙をこする、やわらかい音（速さで変わる）。点や完了は、ペンタトニックの小さな音とベル

## 支援者メニュー（右上の点を1.2秒長押し、案B）
- 場面（3×2、絵つき）／この場面（線の太さ・道・形・点の数、紙を消す）／みんな共通：手助け
- くわしく：場面ごとの説明、触れ方、見た目、音、説明をもう一度／もとにもどす・とじる
- 「紙を消す」は支援者メニューの中だけ（子どもの画面にボタンなし）

## 約束
- 子ども画面に文字なし。点滅なし。音はやわらかく音量上限。描いた絵・名前・記録・録音・顔を保存しない。治療効果をうたわない。
- 支援者用の説明画面に、本の留意点（大人が手を添える、タイミングよく手を離させる）を書いてある

## 決定事項
1. アプリ名：かく あそび（kaku-asobi）
2. 場面の出し方：6場面は最初から全部選べる（子どもの状態や、その日の興味に合わせて支援者が選ぶ）
3. 「消す」：支援者メニューの中だけ

## 改善（2026-11-03 指摘への対応）
- なぞる：ペンの太さを溝の幅に合わせ、指先の位置に輪を出す。始点（緑）を大きくする
- 円：円を大きくし、中央に置く。始点（緑）と、向きの矢印を出す。見本のあとは、点線の円が残る
- 点を結ぶ：つなぐ線を、すべての手助けで点線で出す。次に結ぶ線は濃い金色。点を大きくする
- 点線：点を大きくする（太い 0.036U／細い 0.026U）
- ぬる：型の外へ約14%はみ出しても色がつく。手助け「小さい」は、約96%までぬらせる（途中で自動完了しない）
